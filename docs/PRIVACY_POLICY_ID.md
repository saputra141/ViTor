# Kebijakan Privasi ViTor

**Tanggal berlaku:** [ISI TANGGAL RILIS]

ViTor adalah aplikasi penyunting video yang memproses media pilihan pengguna secara lokal di perangkat.

## Informasi yang dikumpulkan
ViTor tidak meminta pembuatan akun dan tidak mengirimkan file video, audio, subtitle, atau proyek pengguna ke server pengembang. Versi aplikasi ini tidak menggunakan iklan, analitik pihak ketiga, atau pelacak.

## Akses file dan media
Pengguna memilih video, audio, atau file subtitle melalui pemilih dokumen Android. Aplikasi hanya mengakses file yang dipilih pengguna untuk pratinjau, penyuntingan, penyimpanan proyek, dan ekspor. Hasil ekspor video dapat disimpan ke folder Movies/ViTor.

## Penyimpanan
Data proyek disimpan di ruang penyimpanan privat aplikasi pada perangkat. Penghapusan data aplikasi atau pencopotan aplikasi dapat menghapus proyek yang tersimpan di ruang tersebut. File sumber yang dipilih pengguna tidak diubah oleh proses ekspor.

## Berbagi data
ViTor tidak menjual, menyewakan, atau membagikan data pengguna kepada pengembang atau pihak ketiga. Aplikasi tidak memiliki layanan akun atau sinkronisasi cloud.

## Keamanan
Akses media diberikan melalui pemilih dokumen Android dan dibatasi pada file yang dipilih pengguna. Pengguna bertanggung jawab menjaga salinan cadangan file sumber dan hasil ekspor.

## Privasi anak
ViTor bukan aplikasi yang dirancang khusus untuk anak-anak dan tidak secara sengaja mengumpulkan informasi pribadi anak.

## Perubahan kebijakan
Kebijakan ini dapat diperbarui jika fitur atau praktik pemrosesan data aplikasi berubah. Versi terbaru harus dipublikasikan pada URL kebijakan privasi yang dapat diakses publik sebelum pengiriman ke Google Play.
